# API and state contract

All `/api/*` endpoints require `Authorization: Bearer <API_TOKEN>`. The local frontend proxy injects this token; Swagger's Authorize button accepts the raw token. Internal `/v1/*` agent endpoints require `X-Agent-Token`.

| Method | Route | Behavior |
| --- | --- | --- |
| GET | /api/incidents | Latest 100 incidents |
| POST | /api/incidents | Create, returns 201; required service, title, description, severity=P1/P2/P3; optional scenarioId |
| GET | /api/incidents/{id} | Incident, analysis, approval, execution, audit events |
| POST | /api/incidents/{id}/analyze | Investigate OPEN or ANALYSIS_FAILED incident |
| POST | /api/incidents/{id}/approval | decision=APPROVE/REJECT, reviewer, note; required nonblank fields |
| POST | /api/incidents/{id}/execute | Execute APPROVED incident or return existing RESOLVED receipt |
| GET | /api/scenarios | Ten reproducible scenario summaries |
| GET | /api/runbooks | Runbook library |
| POST | /api/runbooks | Ingest/replace custom id, service, title, content; returns 201 |
| GET | /actuator/health | Backend health |
| GET | /v3/api-docs | Generated OpenAPI document |

Analysis response is stored as JSONB under `analysis`. It contains `mode`, `root_cause`, `reasoning`, `confidence`, `evidence`, `citations`, `recommendation`, `tool_calls`, and `warnings`. Recommendation contains action, risk, executable, human_approval_required, explanation. Citation contains runbook_id, chunk_id, title, content, score.

Execution result contains success, simulated, stable receipt, action, before/after metric snapshots, and verification text. Audit events are ordered by numeric ID. `INCIDENT_CREATED`, `ANALYSIS_COMPLETED`, `HUMAN_APPROVE`/`HUMAN_REJECT`, and `SIMULATION_EXECUTED` describe the successful workflow. `ANALYSIS_FAILED` records a retryable analysis failure without leaking provider credentials or raw errors.

Invalid payloads return 400. Missing/invalid tokens return 401. Unknown incidents return 404. Invalid lifecycle transitions return 409. Proxy/provider failures generally return 502; the analyze endpoint instead persists ANALYSIS_FAILED and returns the incident with HTTP 200, so clients must inspect its status and last_error. Invalid UUID paths return 400. Backend Swagger and agent OpenAPI schemas are generated by their respective frameworks.

The request description is limited to 8000 characters; custom runbook content to 16000. Human decisions require a reviewer label and note. There is one immutable decision per incident. Rejected incidents cannot be reopened in this MVP; create a new incident if additional investigation is needed.
